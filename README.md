# 🚀 Sleek Full Stack Developer Portfolio (React.js & Node.js Specialist)

An ultra-modern, high-performance personal portfolio engineered specifically for **Full Stack Developers** specialized in **React.js** and **Node.js**.

---

## ✨ Features & Architecture

- ⚡ **React.js & Node.js Core Showcase**: Spotlights your skills across both ends of the stack—from 60fps reactive frontends, state management (Redux/Zustand), and Next.js to high-throughput Node.js microservices, Express/NestJS, Socket.io, and asynchronous concurrency.
- 🧑‍💻 **Comprehensive "About Me" Section**:
  - Interactive multi-tab layout: **My Journey**, **React & Node Craft**, and **4 Core Pillars**.
  - Quick specs grid (Primary Focus, Degree, Core Languages, Offline Passions).
  - Direct social profile badges with instant copyable email.
- 💻 **Interactive CLI Terminal**:
  - Fully working developer terminal prompt (`visitor@alex-vance:~$`).
  - Supports commands: `help`, `react`, `node`, `skills`, `projects`, `experience`, `contact`, `npm run dev`, `cat resume.txt`, `sudo hire`, `clear`, and `theme [dark|light]`.
  - Touch/mobile-friendly quick action buttons and command history (Up/Down arrow navigation).
- 🛠️ **Dynamic Skills Matrix**:
  - Category filters: *All Skills*, *React & Frontend*, *Node.js & Backend*, *Databases & Cache*, *DevOps & Cloud*, and *Architecture*.
  - Proficiency mastery meters, years of experience, and library tags.
- 📂 **Featured Projects with Architecture Deep Dives**:
  - Real-world production case studies (Real-time collaboration, media streaming, telemetry ingestion, e-commerce).
  - Modal deep-dives detailing client architecture (React), server architecture (Node.js), caching layers, and key engineering hurdles solved.
- 🎨 **Visual Polish & Design System**:
  - Cyberpunk-meets-minimalist aesthetic with glowing radial gradients.
  - Interactive particle constellation canvas reacting to mouse movement.
  - Dark / Light mode toggle with `localStorage` persistence.
  - Web Audio API synthesizer sound effects (toggleable audio feedback, zero audio asset dependencies).
  - Built-in visual printable resume viewer.

## ⚡ Quick Start

### Option 1: Direct Double-Click (Zero Install Needed!)
Because this portfolio is built with modern web standards and standalone CDN scripts, you can simply **double click `index.html`** in Windows Explorer or open it in Google Chrome, Microsoft Edge, Firefox, or Safari!

### Option 2: Run via Local Server (Node / npm)
In your terminal, navigate to the portfolio folder and run:
```bash
# Start a local static server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ How to Customize

All content is cleanly separated and easy to personalize:

1. **Personal Information & Bio**:
   - Open [`index.html`](./index.html) and search for `Alex Vance` to update your name, title, email, and social media URLs.
2. **Skills & Mastery Levels**:
   - Open [`script.js`](./script.js) and edit the `SKILLS_DATA` array. Adjust percentages, experience years, or add new frameworks.
3. **Projects & Case Studies**:
   - In [`script.js`](./script.js), edit the `PROJECTS_DATA` array. Update project titles, live links, GitHub repos, and architectural breakdowns.
4. **Resume**:
   - Edit the resume modal content inside [`index.html`](./index.html#L530) to customize your work history and education.

## 🌐 One-Click Free Deployment

### Deploy to Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project root folder.
3. Done! Your site is live on `https://your-portfolio.vercel.app`.

### Deploy to Netlify
- Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop).

### Deploy to GitHub Pages
1. Push this folder to a GitHub repository.
2. Go to **Settings > Pages** and select `main` branch root.
3. Your portfolio is live on `https://<username>.github.io/<repo-name>`.
